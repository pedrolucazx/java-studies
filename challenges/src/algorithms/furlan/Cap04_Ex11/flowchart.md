# Capítulo 4 - Exercício 11: Gerador de Números Perfeitos

> **Livro:** Algoritmos E Lógica Da Programação  
> **Capítulo:** 4 - Estruturas de Programação

---

## 📝 Enunciado

Escreva um fluxograma que gere os N primeiros números perfeitos. Um número perfeito é um número inteiro para o qual a soma de seus divisores próprios (todos os divisores positivos, exceto o próprio número) é igual ao próprio número.
