## 💡 Observações

O enunciado original não especifica as fórmulas para cálculo das médias (provas, trabalhos e final), nem o critério de aprovação. Foram adotados os seguintes critérios como suposição para a resolução do problema:
- Média de Provas (MP) = `(P1 + P2 + P3 + P4) / 4`
- Média de Trabalhos (MT) = `(T1 + T2 + T3 + T4) / 4`
- Média Final (MF) = `(MP * 0.8) + (MT * 0.2)`
- Critério de Aprovação: `MF >= 6.0`
