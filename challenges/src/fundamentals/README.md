## 🚀 Como Executar

```bash
# Compilar
javac Ex01_AreaCircle.java

# Executar
java Ex01_AreaCircle
```

## 📚 Conceitos Aplicados

- Tipos primitivos (int, double, String)
- Entrada de dados com Scanner
- Saída de dados com System.out (print, println, printf)
- Operadores aritméticos, relacionais, lógicos e módulo (%)
- Estruturas condicionais: if, else, if-else, switch
- Estruturas de repetição: for, while, do-while
- Controle de fluxo: break
- Funções e métodos auxiliares
- Classe Math (Math.PI, Math.pow, Math.sqrt, Math.random)
- Manipulação de Strings
- Lógica de validação (intervalos, paridade, divisibilidade, maior valor, status)
- Acúmulo e comparação de valores
- Interação com o usuário e validação de entrada
